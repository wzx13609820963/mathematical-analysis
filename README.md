# 从高等数学到数学分析

副标题：严格基础、经典理论与现代分析。

本项目面向已经系统学过工科高等数学、希望进入严格数学分析与现代分析的读者。教材以定义的形成、定理依赖、完整证明、反例和结构性观点为主，不重复一般微积分课程中的基础计算训练。

## 编译

在项目根目录运行：

```powershell
.\book\build.ps1
.\book\build-solutions.ps1
```

脚本会在 `PATH` 或 `C:\texlive` 中查找 LuaLaTeX，连续编译两次，并把成品复制到 `output/pdf/`。构建过程使用任务目录中的临时字体缓存，成功发布后自动清理。

## 版本控制约定

每次新增或实质修改章节时，应同步处理正文、习题、独立解答和实际受到影响的活登记表，并按变更范围完成构建与 PDF 页面检查。总目录和写作规范只在宏观规则确实改变时更新，不作为普通章节提交的固定组成。通过检查后形成范围明确的 Git 提交，再同步到 GitHub。LaTeX 中间文件和页面检查图片不进入版本库。

总目录、写作规范和全书排版由宏观设计任务统一维护；章节内容任务按 `AGENTS.md` 执行，不自行改动上述文件。
