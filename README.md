# 从高等数学到数学分析

副标题：严格基础、经典理论与现代分析。

本项目面向已经系统学过工科高等数学、希望进入严格数学分析与现代分析的读者。教材以定义的形成、定理依赖、完整证明、反例和结构性观点为主，不重复一般微积分课程中的基础计算训练。

## 编译

在项目根目录运行：

```powershell
.\book\build.ps1
.\book\build-solutions.ps1
```

脚本会在 `PATH` 或 `C:\texlive` 中查找 XeLaTeX，连续编译两次，并把成品复制到 `output/pdf/`。

## 版本控制约定

每次新增或实质修改章节时，应同时更新正文、习题、独立解答、必要的目录或写作规范，并完成编译与 PDF 页面检查。通过检查后形成一个范围明确的 Git 提交，再同步到 GitHub。LaTeX 中间文件和逐页检查图片不进入版本库。

总目录、写作规范和全书排版由宏观设计任务统一维护；章节内容任务按 `AGENTS.md` 执行，不自行改动上述文件。
