# 《从高等数学到数学分析：严格基础、经典理论与现代视野》目录审校与覆盖报告

## 一、审校结论

正式目录已经完成内容覆盖、逻辑依赖、重复主题、章节粒度、标题体例和编号连续性六类检查。原计划的240个问题均已进入正文主线或明确组织的拓展专题，没有发现整项遗漏。修订后的正式目录为四卷、二十一编、第0章至第127章，共128章、903个核心章内小节和39个附录小节。

目录已经冻结为1.1版。冻结的是四卷、二十一编和核心章的顺序；写作过程中仍可修正错字、调整表述、增加不改变主线的小例子或反例，但不得在没有整体复审的情况下改变章序或删除核心内容。

标题体例已经统一为名词性、陈述性的教材标题。“从定义证明数列极限”等课程任务式章名已改为“极限定义中的误差控制”；章内选读内容改设“拓展专题”层级，整章选读内容在卷首说明中集中列示，不再在标题末尾附加“（拓展）”。

## 三、发现并解决的逻辑依赖问题

### 1. Taylor积分余项出现过早

积分余项原来与其他Taylor余项一同放在积分定义之前，若在那里完整证明会形成前置依赖倒置。正式目录在第24章只说明其形式和后置原因，完整证明放在第30.12节。

### 2. 多元极限理论展开不足

原细化稿只用一个小节概括多元极限和路径法，不能承载原计划第96—98问。正式目录将第44章扩充为严格定义、Heine判据、路径否定法、直线路径反例和多元连续性五个连续小节。

### 3. 度量空间中的连通性被压缩得过度

连通性原先只在紧致性章节末尾出现一句。正式目录将第48章改为“度量空间中的紧致性与连通性”，补入分离、连通分支、道路连通及保持定理。

### 4. 现代微积分基本定理缺少关键前置结论

原细化稿没有明确安排“单调函数和BV函数几乎处处可导”，也没有列出Lebesgue微分定理证明所需的覆盖与极大函数工具。现已补入第92.6—92.7节及第94.2—94.4节。

### 5. Sobolev弱极限缺少泛函分析基础

只定义弱收敛不足以支持直接变分法。第104章现已包含弱星收敛、Banach–Alaoglu、反射性与弱紧致性；第125章再把这些结论用于Sobolev空间。

### 6. 向量分析的“统一”原先可能只停留在口号

经典Green、Gauss、Stokes仍保留在第61章；第62章加入外代数、微分形式、拉回、外微分、定向流形和广义Stokes，使统一陈述具有严格数学内容。

### 7. \(L^p\)对偶表示缺少Radon–Nikodym基础

Radon–Nikodym定理已由可跳过的拓展章调整为主线第97章，第103章的\(L^p\)对偶表示明确依赖它，并注明一般测度空间中需要适当的标准假设。

## 四、重复主题的处理

以下内容表面重复，实际是有意设置的层次递进，因此没有合并：

- 第18、45、48章分别研究实数轴、有限维欧氏空间和一般度量空间中的紧致与连通。
- 第25章从微分学反例说明\(C^\infty\)不蕴含解析；第43章从幂级数正面建立解析函数理论。
- 第30章是Riemann框架的微积分基本定理；第96章是绝对连续和Lebesgue积分框架的最终版本。
- 第63—65章先在具体函数空间中形成直觉；第98章以后再抽象为一般Banach和Hilbert空间。
- 第108章给出抽象正交系的Parseval理论；第113章专门落实到三角Fourier系。
- 第104章建立一般弱收敛理论；第125章研究它在\(H^1\)和变分法中的具体作用。

已经拆开的不合理重复包括：Taylor积分余项的证明、紧算子专题以及解析函数的两个同名章节。紧算子与谱理论现集中放在附录G，不再混入最小二乘章节。

## 六、有意不纳入本书主线的内容

为了保持“数学分析及其自然延伸”的边界，以下内容没有继续扩张为独立主体：

- 复变函数、留数理论和复解析函数；
- 概率论、随机过程和遍历论；
- 一般拓扑空间、拓扑向量空间与局部凸空间的系统理论；
- 算子谱理论、C*-代数和无界算子的完整理论；
- 调和分析中的奇异积分、Littlewood–Paley理论；
- 非线性泛函分析、变分法和偏微分方程正则性的系统课程。

这些方向会在相应章节末尾作为后续路线指出，但不继续占用本书主线，以免教材失去中心。

## 七、冻结后的写作约束

1. 正文严格按照正式目录编号推进。
2. 拓展节不作为未标注主线章节的必要前提。
3. 若某证明必须使用后置知识，应明确延后证明，不得暗中循环引用。
4. 同一概念在不同层次重现时，必须说明新增结构，不能原文重复。
5. 每章均须包含反例和条件必要性检查，但不把相同反例无意义重复使用。
6. 新增专题原则上放入章内拓展节或附录；需要改变章序时，必须重新进行全书依赖审校。
