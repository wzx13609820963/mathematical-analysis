# 《从高等数学到数学分析：严格基础、经典理论与现代分析》目录审校报告

> 对应目录版本：2.0（宏观设计稿）
>
> 审校日期：2026年8月12日

## 一、结论

当前总目录包括七卷、三十一编、第0章至第210章，共211章；章号连续且无重复。目录尚未冻结，但已经形成可约束各章写作的主干。具体内容编写对话不得自行增删、移动或重命名卷、编、章；宏观结构变更统一回到本书总体设计对话处理。

原240问覆盖的经典数学分析、实分析和初步泛函分析内容全部保留。2.0版取消了“复分析、一般拓扑、概率、调和分析、算子理论和偏微分方程只作后续路线”的旧边界，把它们按逻辑依赖扩展为后三卷正文，使全书由一套扩大的“数学分析”教材转向综合性的“分析学”教材。

## 三、关键依赖调整

1. 第127章不再过早总结全书。原总结章后移为第210章，避免把尚未建立的复分析、概率和PDE仅作为展望。
2. 一般拓扑安排在复分析的正规族、流形和Radon测度之前；网、滤子和紧致性只在序列不再充分时引入。
3. 复分析先由复可微和Cauchy理论建立局部刚性，再进入奇点、留数、解析延拓、共形映射和调和函数。
4. 流形与微分形式放在多元分析、一般拓扑和经典Stokes定理之后，使广义Stokes不依赖未定义的结构。
5. 概率论安排在Lebesgue积分、乘积测度、\(L^p\) 和Radon--Nikodym定理之后；条件期望先以测度论构造，再进入鞅。
6. 高阶调和分析安排在Fourier级数、Fourier变换、分布和 \(L^p\) 理论之后。
7. 谱理论安排在Banach/Hilbert空间和紧算子之前提之后；PDE安排在Sobolev、分布、变分法和算子半群之后。

## 四、重复主题的层级分工

- 第18、45、48、132章分别处理实数轴、有限维欧氏空间、度量空间和一般拓扑空间中的紧致性；后章必须说明新增加的结构层次，不重复前章证明。
- 第25、43、138—149章分别处理实光滑与实解析的分野、实幂级数理论和复全纯函数理论。
- 第30、96、155章分别给出Riemann框架、Lebesgue/绝对连续框架和流形上的微积分基本定理。
- 第110—115章建立经典Fourier理论；第175—184章建立Schwartz空间、极大函数、插值和奇异积分等高阶方法。
- 第121—126章建立分布、Sobolev与弱解的入口；第201—209章在此基础上系统研究PDE。
- 第97章建立符号测度和Radon--Nikodym定理；第158—164章研究拓扑上的正则测度、表示定理、Haar测度和遍历思想。

## 五、附录边界

附录只承担参考性或前置补充任务：集合论、有限维线性代数、估计工具、反例索引、符号与依赖表、代数预备、历史术语与阅读指南。紧算子与谱理论已经进入第七卷正文，不再放在附录。习题详细答案属于独立解答册，不属于正文附录。

1. 正文按2.0目录中给定的章名和小节主线写作。
2. 内容对话可在章内增加必要的小小节、例题和反例，但不得修改总目录文件。
3. 若发现逻辑缺口、重复或必须改变章序，应在交付说明中提出，由宏观设计对话统一修改。
4. 拓展专题不得成为后续主线的隐含前提。
5. 每次宏观目录修改后必须重新检查章号连续性、前置定义、定理依赖和附录边界。
