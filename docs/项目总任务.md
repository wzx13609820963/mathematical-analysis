# 项目总任务：完成《从高等数学到数学分析》教材

## 目标

按照当前宏观目录和《教材写作规范》，持续编写一套从工科高等数学过渡到严格数学分析并系统进入现代分析的综合教材，同时维护独立习题解答册、可编译 LaTeX 工程和经过视觉检查的 PDF 成品。

## 基本要求

- 以严格定义和逻辑依赖为主线，不重复一般高等数学的基础计算课程；
- 重要定理给出完整或接近完整的证明，并标明每项条件的用途；
- 系统配置正例、反例、边界例和常见误解；
- 习题承担补充正文、技术训练、结构迁移和经典结果重建的作用；
- 每道正式习题在独立解答册中具有对应的详细解答；
- 集合论采用分层处理：第0章给出使用底线，附录A只解释当前正文已经使用的集合构造与选择；Zorn 引理、超限递归等内容在首次真正需要处建立；
- 实质更新按 `AGENTS.md` 的分级验收执行：局部正文修改只构建受影响的正文主文件，涉及习题、标签、公共样式、解答或正式发布时再构建解答册；逐页检查的范围必须与实际变更级别相符。

## 每次更新的完成条件

1. 修改范围与总目录、写作规范和当前依赖一致；
2. 新增或改变的习题与详细解答逐题对应；
3. 交叉引用、稳定键和载入路径没有失效或循环；
4. 先运行项目静态检查，再按 `AGENTS.md` 的变更等级使用 LuaLaTeX 构建相应主文件；
5. 日志不存在编译错误、未定义引用、重复标签、字体异常或未处理的公式越界；
6. 页面检查覆盖规定范围，并准确区分逐页检查与抽查；
7. 活登记表、项目状态和发布文件名与实际内容一致；
8. 使用范围明确的 Git 提交同步到 GitHub。

## 对话分工

- 本书宏观设计对话维护总目录、写作规范、全书排版、卷间依赖和项目规则；
- 每个内容对话只负责编写或修订一章，并同步完成对应习题与独立解答；
- 内容对话发现宏观问题时只提出建议，不直接修改总目录和全书规范。
