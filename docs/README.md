# 项目文档索引

本目录保存教材编写阶段的状态、登记表、审校记录和迁移资料。当前规则与历史记录分开维护；历史文件保留当时的章号、页数和判断，不因后续重构而回写。

## 当前有效文件

| 文件 | 职责 | 何时更新 |
|---|---|---|
| `../教材总目录.md` | 卷、编、章及章内主线的唯一宏观依据 | 仅宏观设计任务调整目录时 |
| `../教材写作规范.md` | 成书原则、工程操作和验收标准 | 全书规则改变时 |
| `../AGENTS.md` | Codex 在本仓库中的任务入口、读取范围和权限边界 | 工作流程或协作边界改变时 |
| `项目总任务.md` | 当前里程碑、未完成事项和项目状态 | 完成阶段性任务后 |
| `新对话使用说明.md` | 开启章节写作、修订或校核任务时的提示词模板 | 工作流改变时 |
| `NOTATION.md` | 编写阶段的活符号表 | 全局符号新增、删除或改变时 |
| `TERMINOLOGY.md` | 编写阶段的活术语表 | 译名或术语约定改变时 |
| `DEPENDENCIES.md` | 已写正文的直接依赖、稳定标签和无环约束 | 新章完成或跨章依赖改变时 |

仓库根目录的 `README.md` 只介绍项目和当前发布范围；`book/README.md` 只说明 LaTeX 工程、构建方式和版式模式。两者不另行制定写作规则。

## 历史与过程资料

- `目录审校/`：目录版本的粒度审计和复审报告。文件名带版本号；旧版本只解释目录演变。
- `迁移/`：正文、解答和标签迁移的映射与实施记录。已完成的迁移文件不再充当待办清单。
- `审查报告/`：首次校核、整改记录和复核报告。报告对应特定版本快照，后续结果不得覆盖旧报告。
- `文件卫生/`：候选清理清单。第一次检查只列路径、大小、哈希和建议，不据此自动删除文件。

## 规则冲突的处理

在仓库文件内部发生表述差异时，按以下顺序核对：

1. 当前任务的明确要求和 `AGENTS.md` 的权限边界；
2. `教材总目录.md` 的卷、编、章归属；
3. `教材写作规范.md` 的成书与验收要求；
4. `NOTATION.md`、`TERMINOLOGY.md`、`DEPENDENCIES.md` 的当前登记；
5. README、项目状态和历史报告。

历史报告中的旧章号、旧页数或旧构建范围是当时事实，不应据此覆盖当前目录和登记表。发现当前文件彼此不一致时，应核对源文件并在同一任务中更新有关现行文档；不能通过修改历史报告制造表面一致。
