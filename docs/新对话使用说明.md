# 新对话使用说明

## 一、创建新对话前

1. 在 Codex 中选择仓库根目录 `C:\Users\26857\Desktop\数学分析` 作为工作区。
2. 确认上一个任务已经提交并推送，工作区没有来源不明的未提交修改。
3. 一次对话只负责一章，或负责同一章中边界明确的一组小节。不要同时让多个对话在同一工作区修改文件。
4. 若需要并行编写，先为每个任务建立独立 Git 分支和 worktree；否则按章串行推进。

仓库根目录的 `AGENTS.md` 会作为项目指令被自动发现。普通 Markdown 和 LaTeX 文件不会全部自动读入；提示词必须明确要求读取本章所需的目录、规范、前言、样章和前置章节。

## 二、正文与习题的推荐提示词

将下列方括号内容替换为实际信息：

```text
请编写《从高等数学到数学分析》的第[章号]章《[章名]》。本对话只负责这一章的正文、章末习题和独立详细解答。

开始前请完整读取仓库根目录 AGENTS.md、教材写作规范.md，以及教材总目录.md 中本章和相邻章节；再读取 book/frontmatter/preface.tex、book/chapters/vol1/part1/chapter0.tex、当前章所依赖的已完成章节、book/analysisbook.sty、book/main.tex 和 book/solutions.tex。不要修改教材总目录.md、教材写作规范.md、AGENTS.md 或全书级排版。

按目录既定小节写成连续、客观、严格的教材正文。避免问答式标题、成串反问、“真正理解”“本质上就是”“不是……而是……”等模板化语言。重要定理给出完整或接近完整的证明，明确条件用途；配置典型例、边界例、反例和常见错误。不要重复高等数学基础计算。

本章习题按写作规范分层配置，并在对应 solutions 文件中逐题给出详细答案。完成后更新主文件的章节载入，分别编译正文与解答册，检查日志并渲染 PDF 做视觉检查。最后报告修改文件、习题数量、验证结果以及任何需要宏观设计对话处理的问题。未经我明确要求，不要修改总目录，也不要强推或改写 Git 历史。
```

## 三、只修订已有章节的推荐提示词

```text
请审校并修订第[章号]章《[章名]》，不新增下一章内容。先读取 AGENTS.md、教材写作规范.md、总目录对应条目、前言、当前正文和当前解答。

本轮重点是：[数学严格性／证明补全／反例体系／去除模板化和AI腔／习题增强／排版]。保留正确且成熟的内容，不为改写而改写。正文和解答须同步；不得改总目录和全书写作规范。完成后编译、检查 PDF，并逐项说明实质修改。
```

## 四、建议的任务粒度

- 第0—19章等基础章：通常一章一个对话。
- 证明密集或跨度较大的章：先完成正文，再在同一对话补习题和解答；不要拆给互不知情的两个对话。
- 选读或高阶章：仍以一章一个对话为宜，并在章首明确依赖和可跳读关系。
- 全书目录、术语、符号、排版或卷间依赖：回到宏观设计对话处理。

## 五、Git 建议

最稳妥的方式是串行工作：每章开始前同步 `main`，完成并验证后提交、推送，再开启下一章。若多个章节并行，应为每章使用 `chapter/章号-短名` 分支和独立 worktree，审核后再合并到 `main`。不要让两个对话同时在同一个工作区和同一个分支上写作。
