# 新对话使用说明

本文件给出章节内容任务的启动方式。它不重复《教材写作规范》，也不取代 `AGENTS.md`；具体读取范围、权限和验收等级以这两个文件为准。

## 一、工作区与自动读取

1. 新任务使用仓库根目录 `C:\Users\26857\Desktop\数学分析` 作为工作区。
2. 根目录的 `AGENTS.md` 会被项目机制发现；普通 Markdown、LaTeX、PDF 和前一对话内容不会因此全部自动读入。
3. 提示词应说明章号、章名、任务类型和允许修改的文件。模型随后按 `AGENTS.md` 分层读取，不必在提示词中逐个罗列所有主文件。纯 Git 或状态查询可以直接提出，不需要套用章节提示词。
4. 开始前确认上一任务已经提交，或至少确认工作区中的未提交修改归属清楚。两个任务不能同时在同一分支和同一工作区改同一批文件。

## 二、建议的任务边界

- 通常一章一个任务，正文、章末习题和对应解答由同一任务维护。
- 很长的章可以按连续的数学阶段分轮完成，但每轮必须说明边界，并保持同一章的定义、标签和习题设计连续。
- 局部勘误、单个证明补全或一次专项语言修订可以小于一章；不要借局部任务重写无关段落。
- 总目录、写作规范、全书排版、卷间依赖和项目规则由宏观设计任务维护。
- 首次正式校核是“只审不改”的独立任务；整改和复核另开轮次，不能与首次校核混为一轮。

## 三、新写或大幅重写一章

将方括号替换为实际内容：

```text
请编写《从高等数学到数学分析》第[章号]章《[章名]》。本任务只负责本章正文、章末习题、对应详细解答，以及因本章产生的活登记表和载入文件更新。

开始前按 AGENTS.md 分层读取：核对《教材总目录.md》中本章及相邻条目、《教材写作规范.md》的相关规定、当前源文件、直接前置章节，以及 NOTATION、TERMINOLOGY、DEPENDENCIES 中有关登记。只有本章涉及共同语言或需要比较样章语气时才读取第0章；只有公共样式或载入关系受到影响时才读取 analysisbook.sty、main.tex 和 solutions.tex。

按既定章界形成连续的理论叙述。重要定义要说明所解决的问题，主要定理给出完整或接近完整的证明，核对条件用途、反例和与高等数学旧知识的关系。不要套固定节数或固定教学模块，不要把正文写成定义和定理的清单，也不要为追求篇幅重复解释。

习题数量和层次由本章内容决定；默认题不标必做，选做题使用星号，并在独立解答册逐题给出详细解答。不得修改总目录、全书写作规范或 AGENTS.md。完成后运行项目检查和规定级别的构建、页面检查，报告实际修改、习题与解答数量、验证范围和需要宏观任务处理的问题。
```

## 四、修订已有章节

```text
请审校并修订第[章号]章《[章名]》，不新增下一章内容。本轮重点是：[数学严格性／证明补全／解释与节间衔接／反例／习题／语言／局部排版]。

按 AGENTS.md 读取当前正文、对应解答、总目录相关条目、适用的写作规范和活登记项；再按实际依赖读取直接前置及引用处。保留数学上正确且叙述成熟的内容，不为改写而改写。正文、习题和解答同步维护；不得改变章界或全书排版。完成后按变更等级验证，并说明哪些页面实际查看过。
```

如果任务只改局部语言或单个公式，应在提示词中写出具体位置。此时无须要求读取前言、第0章、整本主文件或全部解答。

## 五、首次正式校核

```text
请对第[章号]章《[章名]》进行第一次正式校核。本轮只审查，不修改正文、解答、样式、目录、主文件或构建脚本。

按 AGENTS.md 和《教材写作规范》的校核制度检查目录与依赖、数学陈述、证明、反例、习题与解答、语言、排版和文件卫生。需要编译或渲染时只使用本任务的 tmp/tasks/<task-id>/。在 docs/审查报告/ 的对应范围生成 YYYY-MM-DD-首次校核.md，准确记录版本、实际检查范围、问题等级、文件与行号或 PDF 页码，以及未完成检查。抽查不得写成逐页检查或全量通过。
```

首次报告完成后，再分别启动“按报告整改”和“复核整改结果”的任务。

## 六、Git 协作

串行写作最稳妥：开始前同步 `main`，完成并验证后提交、推送，再开启下一章。需要并行时，为每个任务使用 `codex/` 前缀的独立分支和独立 worktree；不要让两个任务在同一工作区共同修改章节、解答或主文件。

提交应包含当前任务实际改变的正文、解答、载入文件、活登记表、图表或报告，不因文件类型而遗漏，也不顺手纳入其他任务的改动。未经明确要求不强推、不改写历史。
