## 二、重写重点

### 1. 教材叙述

逐章检查了定义以前的铺垫、定理之间的承接、证明以后的解释以及例题和反例的安放位置。改写时删去了重复预告、同义小结、过于整齐的教学模块和空泛的过渡语；能够由具体命题说明的地方，不再使用“机制”“接口”“统一框架”等概括性标题。最终全文关键词检查未检出反复使用“真正”“本质”“核心”“值得注意的是”“从这个角度看”“这一机制”“统一框架”“结构主线”“接口”“适用边界”“严格边界”或“预告”的情况。

重写后的段落以数学问题本身推进：先交代为什么需要一个概念，再给出准确表述；长证明在关键转折处说明所用条件，短证明不人为拆成固定步骤。与工科高等数学的联系放在相应结论附近，不再集中写成重复的章末清单。

### 2. 数学内容

本轮对已有材料作了实质增补。主要工作包括：

- 补足有序域、Archimedes性质、稠密性和确界运算中的论证细节；
- 重写有限小数、无限小数和周期小数进入实数系统的论证；
- 加强Dedekind分割的运算、序、逆元和完备性证明；
- 补齐Cauchy构造中绝对值、代表元估计、商序与有理数嵌入所需的引理；
- 细化数列极限、子列、上下极限和Cauchy准则之间的量词推导；
- 补充完备性各形式的条件说明，并区分有序域中的Archimedes假设与完备性假设；
- 加强函数极限、单侧极限、无穷极限、间断点和一致连续部分的例子、反例及端点讨论；
- 把连续函数在紧集上的有界性、最值、连续模和一致连续之间的依赖写成可逐项核验的证明；
- 扩写原先过短或只给思路的习题解答，尤其是构造题、等价性证明和综合题。

数学复核中还修正了若干容易留下歧义的细节，包括域公理中单位元的明示、映射的数据结构、空指标集的并交、有限或至多可数的术语、孤立点连续性、Heine定理中取点不得等于中心、缺失端点处可能出现无穷单侧极限、空紧集和单点集的特殊情形等。

为减少同一修改者连续阅读造成的遗漏，正文和解答按理论范围分为三组复核：

- 第0至2章与附录A至C：集合语言、实数系统和确界理论；
- 第3至9章：数列、完备性等价形式和Cauchy构造；
- 第10至13章：函数极限、连续性、紧集上的连续函数和一致连续。

三组复核均检查定义的量词、定理假设、证明依赖、反例是否满足全部条件、正文与解答是否一致。复核提出的问题已在本轮整改；整改后未发现阻止当前前三编作为后文基础的数学错误或循环引用。
