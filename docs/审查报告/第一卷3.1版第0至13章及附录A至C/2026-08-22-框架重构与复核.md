## 二、重构前的主要问题

### 1. 完备性理论的顺序不闭合

旧结构在系统建立子列、Bolzano--Weierstrass定理和Cauchy数列以前，已经把若干完备性命题作为同一组等价结论处理；与此同时，递推数列的部分证明又调用尚未正式建立的Cauchy完备性。这使正文虽然包含所需结论，论证次序却不能形成单向依赖。

### 2. 实数构造与分析工具交错

Dedekind构造和Cauchy构造过早并列，后者不得不预支尚未形成的数列理论。读者难以区分两件事：把实数作为完备有序域使用，以及用有理Cauchy列重新构造实数。

### 3. 附录超出当前成书范围

旧附录A至G同时容纳集合论、拓扑、线性代数、张量、测度论、外代数、历史材料和未来章节反例。其中不少条目在当前前三编尚无引用，部分结果要依赖远后于第一卷的理论。附录因此兼有参考表、预告和知识仓库三种职责，不利于当前读者使用，也造成正文与附录重复。

### 4. 少量习题预支后文

原完备性章节的若干题目要求使用当时尚未建立的工具。题目本身有价值，但在新顺序中会破坏本编内部的依赖方向。

## 三、已经完成的整改

### 1. 第二编改为单向推进的理论链

第二编现按下列顺序组织：

1. 数列极限；
2. 单调数列与迭代；
3. 子列与聚点；
4. 上极限与下极限；
5. Cauchy数列；
6. 实数完备性的等价形式；
7. 实数的Cauchy构造。

第8章现集中证明确界原理、单调有界定理、区间套定理、Bolzano--Weierstrass定理和Cauchy完备性之间的蕴含关系，并用Archimedes条件排除非标准有序域中的遗漏。第9章在数列理论和Cauchy完备性均已建立后再作有理Cauchy列商构造，因而不再预支后文。

### 2. 递推数列证明消除循环引用

压缩型区间迭代的收敛性改由尾部下确界、上确界和夹逼定理推出，不再引用后章的Cauchy完备性。复核时进一步处理了区间可能无界的情形：有界性由两项距离估计导出，极限属于不变区间则由闭性推出。

### 3. 附录收缩为当前真正需要的三项

- 附录A《集合构造的约定》只保留受限概括、序偶、Cartesian积、映射、指标族、商集和本书采用的递归/选择约定；
- 附录B《符号与定理版本》记录当前正文反复查用的数集、区间、映射、数列、极限和定理版本约定；
- 附录C《反例索引》只索引第0至13章已经出现并能够在当前基础上核验的反例。

旧附录D至G及附录习题解答暂从成品撤出。序数与超限递归、Zorn引理和Tychonoff定理，未来函数空间、测度、拓扑与微分形式等材料，待正文建立相应理论后再决定是否进入对应卷的附录或正文。

### 4. 习题与解答同步调整

三个预支后文的题目改为当前理论链内可以严格完成的题目：区间套中的任意选点收敛、含正无穷小的有序域中几何数列的反例、上确界的序列刻画。稳定键和正文—解答配对保持一致，解答均给出完整论证。
