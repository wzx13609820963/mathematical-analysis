# 第四卷整卷校核与整改

## 范围与方法

本次整卷校核覆盖第75—89章及其全部166道习题、166份解答，并核对第四卷在总目录、主文件、解答载入、活依赖表、符号表、术语表和附录B、C中的登记。数学内容按定义是否闭合、定理依赖是否无环、证明是否实际使用假设、反例是否满足其余条件四项逐章检查；工程检查和视觉检查范围见同日第十七至二十编整改报告。

## 理论链检查

1. 第75—79章从 Banach 空间的完备性出发，依次建立 Baire 三定理、Hahn--Banach 延拓与分离、弱和弱星拓扑、Banach--Alaoglu 定理、反射性和弱收敛子列。Banach--Alaoglu 使用第38章的 Tychonoff 定理；Eberlein--Šmulian 不由一般紧空间的错误“紧致即序列紧致”推得。
2. 第80—81章把赋范空间中不能普遍使用的正交几何限制在 Hilbert 空间内，依次建立投影、Riesz 表示、Bessel、完备正交系和 Parseval。最小二乘与正规方程只使用有限维投影，不预用后面的 Fourier 理论。
3. 第82—85章区分三角 Fourier 级数的点态/Cesàro 收敛、圆周上的 `L^2` 收敛、实直线上的 `L^1` 变换和 `L^2` 酉延拓。Fourier 反演和 Plancherel 分属不同证明层次，卷积公式中的可积性条件逐项注明。
4. 第86—87章分别以压缩映射和紧性方法处理常微分方程。Picard--Lindelöf 的局部 Lipschitz 条件给唯一性与稳定性；Peano 只从连续性推出存在性，并保留非唯一反例。
5. 第88—89章从试验函数拓扑、正则分布和分布导数进入弱导数，再以 `W^{k,p}` 完备性、`H_0^1`、Poincaré 和 Lax--Milgram 给出 Poisson 方程的弱解。这里建立的是变分弱解的基础模型，不声称一般 PDE 的正则性。

## 目录与篇幅调整

总目录中的第80—89章已经按实际正文重新核对。第82章保留四节，因为点态 Fourier 理论的中心结论集中；第89章扩为六节，以容纳从 Sobolev 空间到一个完整弱解存在唯一性定理的论证。各章实际为4—9页正文，节数为4—6，未为版式对称强行增删章节。第90章以后保持原有章级边界，本轮未以第四卷内容为由提前改写第五卷。

## 尚需在后文建立的事项

- 本卷只给常微分方程的局部存在唯一性和最大延拓；一般流、相图和定性理论留在后续相应范围。
- 分布一章没有定义任意两个分布的乘积；Sobolev 一章没有声称迹定理、紧嵌入或高阶椭圆正则性。
- Plancherel 建立 `L^2` Fourier 变换，但不替代调和分析中弱型估计、奇异积分和 Littlewood--Paley 理论。

## 结论

第四卷的章级结构、定理依赖、主要证明、反例、习题解答和工程载入相互一致。整卷校核中发现的复内积约定、卷积可积性、Fourier 等号情形、Peano 区间、试验函数拓扑和弱解假设等问题均已在本轮改正；未遗留阻断发布的 P1 或 P2 问题。
