# 活符号表

本文件是编写阶段的符号登记表。正文或样式文件新增、删除或改变全局符号时，先更新本表；附录B在正式整理时吸收当前已写范围中对读者有用的条目。局部符号仍须在首次出现处定义。

## 数集与集合

| 源码 | 含义 | 约定 |
|---|---|---|
| `\N` | 自然数集 | `\{0,1,2,\ldots\}`，包含 `0` |
| `\Npos` | 正整数集 | `\mathbb N_{>0}=\{1,2,3,\ldots\}` |
| `\Z,\Q,\R,\C` | 整数、有理数、实数、复数 | 使用样式命令 |
| `\varnothing` | 空集 | 不使用 `\emptyset` |
| `A\subseteq B` | 允许相等的包含 | 严格包含写 `A\subsetneq B` |
| `\mathcal P(X)` | `X` 的幂集 | 先说明 `X` 为集合 |
| `\set{x\in X:P(x)}` | 受限概括 | 不写未受限的 `\{x:P(x)\}` |

## 映射、大小与分析记号

| 源码 | 含义 | 约定 |
|---|---|---|
| `f:X\to Y` | 定义域为 `X`、陪域为 `Y` 的映射 | 像集写 `f(X)` |
| `f^{-1}(B)` | 集合 `B` 的原像 | 不要求 `f` 可逆 |
| `f^{-1}:Y\to X` | 双射的逆映射 | 上下文必须已说明双射 |
| `\abs{x}` | 绝对值或模 | 对象类型由上下文给出 |
| `\norm{x}` | 范数 | 首次使用须说明具体范数；第0章习题0.5局部定义欧氏范数 |
| `:=` | 定义等号 | 普通恒等式仍用 `=` |
| `+\infty,-\infty` | 扩充实数 | 不把它们当作普通实数参与未定义运算 |

## 可数性

| 中文术语 | 精确定义 |
|---|---|
| 有限 | 与某个 `[n]=\{1,\ldots,n\}` 等势，其中 `n\in\N` 且 `[0]=\varnothing` |
| 可数无限 | 与 `\N` 双射 |
| 至多可数 | 有限或可数无限；等价地可单射到 `\N` |
| 不可数 | 不是至多可数 |

正文不得单独使用“可数”来同时指代两种不同概念；引用英文 *countable* 时按原文定义改写为“可数无限”或“至多可数”。

## 稳定交叉引用

| 源码 | 用途 |
|---|---|
| `\chapterref{chap:...}` | 跨章引用 |
| `\sectionref{sec:...}` | 跨节引用 |
| `\theoremref{thm:...}` | 定理引用 |
| `\equationref{eq:...}` | 公式引用 |
| `\exerciseitem{dedekind-cut-basic-check}` | 正文正式习题及其语义稳定键 |
| `\exerciseref{dedekind-cut-basic-check}` | 正文中的习题引用 |
| `\begin{solution}{dedekind-cut-basic-check}` | 解答册中与正文标签自动配对的解答 |

稳定键只承担工程身份，不得手工决定最终显示号。新稳定键不得含当前章号或题号；第一卷前三编迁移后仍保留的数字键只作兼容，不得仿照新增。选做、项目和开放题分别使用 `\optionalexerciseitem`、`\projectexerciseitem`、`\openexerciseitem`，键的规则不变。
