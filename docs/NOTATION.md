# 活符号表

本文件是编写阶段的符号登记表。正文或样式文件新增、删除或改变全局符号时，先更新本表；附录B在正式整理时吸收当前已写范围中对读者有用的条目。局部符号仍须在首次出现处定义。

## 数集与集合

| 源码 | 含义 | 约定 |
|---|---|---|
| `\N` | 自然数集 | `\{0,1,2,\ldots\}`，包含 `0` |
| `\Npos` | 正整数集 | `\mathbb N_{>0}=\{1,2,3,\ldots\}` |
| `\Z,\Q,\R,\C` | 整数、有理数、实数、复数 | 使用样式命令 |
| `\varnothing` | 空集 | 不使用 `\emptyset` |
| `A\subseteq B` | 允许相等的包含 | 严格包含写 `A\subsetneq B` |
| `\mathcal P(X)` | `X` 的幂集 | 先说明 `X` 为集合 |
| `\set{x\in X:P(x)}` | 受限概括 | 不写未受限的 `\{x:P(x)\}` |

## 映射、大小与分析记号

| 源码 | 含义 | 约定 |
|---|---|---|
| `f:X\to Y` | 定义域为 `X`、陪域为 `Y` 的映射 | 像集写 `f(X)` |
| `f^{-1}(B)` | 集合 `B` 的原像 | 不要求 `f` 可逆 |
| `f^{-1}:Y\to X` | 双射的逆映射 | 上下文必须已说明双射 |
| `\abs{x}` | 绝对值或模 | 对象类型由上下文给出 |
| `\norm{x}` | 范数 | 首次使用须说明具体范数；第0章习题0.5局部定义欧氏范数 |
| `:=` | 定义等号 | 普通恒等式仍用 `=` |
| `+\infty,-\infty` | 扩充实数 | 不把它们当作普通实数参与未定义运算 |
| `r(x)=o(\phi(x))` | \(r(x)/\phi(x)\to0\) | 须说明趋近方式，并保证删心邻域内分母非零 |
| `r(x)=O(\phi(x))` | \(|r(x)|\le C|\phi(x)|\) 在相应邻域最终成立 | 常数与邻域允许依赖当前语境，不依赖趋近变量 |
| `f'_-(x),f'_+(x)` | 左导数、右导数 | 凸函数章节在区间内点使用 |
| `C^k(I),C^\infty(I)` | \(k\) 阶连续可微、无穷次连续可微 | \(C^0(I)=C(I)\) |
| `T_{n,a}f`、`R_{n,a}f` | \(f\) 在 \(a\) 处的 \(n\) 阶 Taylor 多项式及余项 | 展开中心和阶数不得省略到产生歧义 |
| `\operatorname{epi}f` | \(f\) 的上图集 \(\{(x,u):u\ge f(x)\}\) | 当前在一维凸函数章节中视为 \(\R^2\) 的子集 |
| `\partial f(x)` | 一维凸函数在 \(x\) 处的次梯度集合 | 当前仅在凸函数语境使用，不与集合边界混淆 |
| `f^*(p)` | 凸共轭 | 当前一维定义为 `\sup_x\{px-f(x)\}`，允许取 `+\infty` |
| `f^{**}(x)` | 凸双共轭 | 当前对有限值凸函数 \(f:\R\to\R\) 使用；一般扩充实值版本还涉及下半连续性 |
| `P:a=x_0<\cdots<x_n=b` | 区间 `[a,b]` 的分割 | `\Delta x_i=x_i-x_{i-1}`；标记分割另为每段选取 `\xi_i\in[x_{i-1},x_i]` |
| `\norm P` | 分割的网格 | `\max_i\Delta x_i`；只在分割语境中使用，避免与向量范数混淆 |
| `S(f,\dot P)` | 标记分割 `\dot P` 对应的 Riemann 和 | `\sum_i f(\xi_i)\Delta x_i` |
| `L(f,P),U(f,P)` | Darboux 下和、上和 | 分别由各子区间上的下确界、上确界定义 |
| `s_n=\sum_{k=1}^n a_k` | 数项级数的部分和 | 级数的和是部分和数列的极限，不把无穷求和当作有限代数运算 |
| `S_{MN}=\sum_{m=1}^M\sum_{n=1}^N a_{mn}` | 二重级数的矩形部分和 | Pringsheim 收敛指 `M,N` 同时独立趋于无穷 |
| `c_n=\sum_{k=0}^n a_kb_{n-k}` | 两个级数的 Cauchy 乘积系数 | 与逐项乘积 `a_nb_n` 区分 |
| `P_N=\prod_{n=1}^N p_n` | 无穷乘积的部分积 | 本书称无穷乘积收敛时要求部分积趋于非零有限值；趋于零另行说明 |
| `\operatorname{p.v.}\!\int f` | Cauchy 主值 | 对称截断的极限；不得代替各奇点或无穷端点分别收敛的通常反常积分 |
| `f_n\rightrightarrows f` | 函数列在指定集合上一致收敛 | 必须同时写明或由上下文唯一确定公共定义域 |
| `\norm{f}_\infty` | 上确界范数 `\sup_{x\in E}|f(x)|` | 当前第25—29章只对有界函数使用；定义域 `E` 须明确 |
| `C_b(E)` | `E` 上有界连续实函数空间 | 使用上确界范数；若 `E` 紧，则与 `C(E)` 相同 |
| `S_N=\sum_{n=1}^N u_n` | 函数项级数的部分和函数 | 逐点或一致收敛均指部分和函数列的相应收敛 |
| `w_n=\sum_{k=1}^n u_kv_{n+1-k}` | 从指标 `1` 起的两个函数项级数的 Cauchy 乘积项 | 与数项级数从指标 `0` 起时的 `c_n` 约定分别使用 |
| `\sum a_n(x-x_0)^n` | 中心为 `x_0` 的幂级数 | 收敛半径写 `R`；有限半径的两个端点分别判断 |
| `T_{N,a}f`、`R_{N,a}f` | Taylor 多项式与余项 | 第29章讨论 `N\to\infty` 时余项是否局部一致趋零 |

## 可数性

| 中文术语 | 精确定义 |
|---|---|
| 有限 | 与某个 `[n]=\{1,\ldots,n\}` 等势，其中 `n\in\N` 且 `[0]=\varnothing` |
| 可数无限 | 与 `\N` 双射 |
| 至多可数 | 有限或可数无限；等价地可单射到 `\N` |
| 不可数 | 不是至多可数 |

正文不得单独使用“可数”来同时指代两种不同概念；引用英文 *countable* 时按原文定义改写为“可数无限”或“至多可数”。

## 稳定交叉引用

| 源码 | 用途 |
|---|---|
| `\chapterref{chap:...}` | 跨章引用 |
| `\sectionref{sec:...}` | 跨节引用 |
| `\theoremref{thm:...}` | 定理引用 |
| `\equationref{eq:...}` | 公式引用 |
| `\exerciseitem{dedekind-cut-basic-check}` | 正文正式习题及其语义稳定键 |
| `\exerciseref{dedekind-cut-basic-check}` | 正文中的习题引用 |
| `\begin{solution}{dedekind-cut-basic-check}` | 解答册中与正文标签自动配对的解答 |

稳定键只承担工程身份，不得手工决定最终显示号。新稳定键不得含当前章号或题号；第一卷既有迁移文件中仍保留的数字键只作兼容，不得仿照新增。选做、项目和开放题分别使用 `\optionalexerciseitem`、`\projectexerciseitem`、`\openexerciseitem`，键的规则不变。
