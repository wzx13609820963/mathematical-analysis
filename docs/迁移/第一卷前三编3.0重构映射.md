## 二、旧第12章的拆分

旧第12章的第1—2节转入新第7章；第3—8节转入新第8章。习题按数学问题拆分：

- 新第7章收入旧习题 `12.1`—`12.4`、`12.20`、`12.22`、`12.25`，它们只依赖部分极限、聚点与抽取定理；
- 新第8章收入旧习题 `12.5`—`12.19`、`12.21`、`12.23`、`12.24`、`12.26`，它们以尾部确界、上下极限或相应运算为主要工具；
- 解答使用原稳定键同步迁移，显示题号由新章的 LaTeX 计数器重新生成。

## 三、习题和解答迁移规则

1. 旧稳定键暂时保留，以保证正文、解答和附录中的既有交叉引用不中断；它们是工程身份，不再等同于新版显示题号。迁移完成后不得据新版章号改造这些键。
2. 正文中所有 `enumerate` 的显示前缀改由 `\thechapter` 产生，删除 `7.`、`12.` 等旧章号硬编码。
3. 删除“按某级配置、共若干题、建议用时若干小时”等配额说明。A、B、C 分组保留，但合章后按新版理论顺序重新排列。
4. 旧第二编、第三编综合作业分别置于新第9章和新第13章之后，题目与详细解答仍然分离。
5. 合并章中重复训练只在题意实质相同且可以合成一题时合并；技术不同或承担不同反例作用的题目继续保留。

## 四、标签和引用

- 新章采用 3.0 目录对应的语义章标签。
- 仍被附录或后文引用的旧章标签可在新章标题处保留为兼容别名；正文叙述统一引用新版章标签。
- 所有手写“第4章”“第7—9章”等显示编号改为 `\chapterref`、`\ref` 或不依赖编号的叙述。
- `book/main.tex`、`book/solutions.tex`、附录中的范围说明和 `docs/DEPENDENCIES.md` 在正文迁移后同步更新。
