# 当前正文依赖登记表

> 3.4版目录处于章级候选定稿阶段。正文现已写完第四卷第20编第89章；第3—9章按数列概念和完备性证明的实际依赖重排，第二卷第36—50章又按一般拓扑和多重积分的实际证明链调整章界。下表记录当前文件、稳定标签和直接依赖。旧版章标签只作为迁移期兼容别名保留，不再用于新增引用。

## 3.4版目录的全书级前置约束

- 一般拓扑的基、乘积、分离、紧致、Tychonoff 定理、网和滤子前置到第二卷第36—41章；第四卷的弱拓扑和弱星拓扑可引用这些结果。
- 第78章先由对偶配对建立弱拓扑和弱星拓扑，再采用一般乘积紧致性证明 Banach--Alaoglu 定理；其直接前置至少包括第38章 Tychonoff 乘积定理和第77章 Hahn--Banach 与对偶性。若以后改用只适用于可分对偶球的度量化证明，必须明确降格为特殊版本，不得冒充一般定理。
- 第79章反射性和弱紧致性位于 Banach--Alaoglu 之后；Eberlein--Šmulian 只在已经区分拓扑紧致和序列紧致后使用。
- 第95章复分析中的 Vitali--Porter 收敛定理依赖正规族；第66章实分析中的 Vitali 收敛定理依赖一致可积性。两个定理不得共用未限定的简称或标签。
- 第50章只证明欧氏空间及参数化子流形上的 Stokes 公式和星形域 Poincaré 引理；第100章在第98章单位分解和第99章抽象微分形式之后证明流形上的一般 Stokes 定理。两层结果不得相互替代或重复完整展开。
- 第72章只建立 Lebesgue 微分定理所需的一维或最低局部极大估计；第122章在第121章插值定理之后系统建立 \(\mathbb R^n\) 中 Hardy--Littlewood 极大算子的弱型、强型和微分定理。后者可以引用前者的动机，但须重新证明高维系统结果。
- 第101章先建立奇异链、奇异同调、奇异上同调、同伦不变性和 Mayer--Vietoris 序列；第102章随后以积分配对和 Mayer--Vietoris 方法证明 de Rham 定理。不得在第102章调用未建立的奇异上同调语言。
- 第96章 Riemann 映射定理可引用第95章正规族和 Montel 定理；第97章调和函数与 Dirichlet 问题不再与共形映射共用同一章闭环。
- 当前附录A处理已写正文使用的集合构造、自然数递归和选择原则。第38章已使用 Zorn 引理、Alexander 子基定理和任意乘积中的同时选点，因此附录A记录选择公理与 Zorn 引理的所用版本；良序原理、超限递归和 Hartogs 引理仍不作为当前基础附录的预备材料。
- 拓扑群及其左右一致结构在第106章 Haar 测度之前建立；局部凸空间、Minkowski 泛函和半范数族在第135章凸泛函之前建立。第二卷不再提前压入这两套尚无直接用途的理论。

“全书级前置约束”只记录宏观目录审校中已经明确、且会影响未来章序或证明版本的关键决定；不为尚未编写的149章逐章推测依赖。后面的章级表只登记已经写入或已经进入近期实施范围的直接前置与稳定标签。二者都服务于编写和校核，不代替正文证明。新增跨章依赖、移动定理或改变允许引用范围时，应从实际源文件核实并同步更新本表。

- 第55章 Carathéodory 延拓的存在性来自外测度构造；唯一性只对 \(\sigma\)-有限预测度在生成的 \(\sigma\)-代数上断言。不得把任意外测度关于递增集合列的连续性当作一般性质。
- 第56章 Lebesgue 测度的正则性通过外测度覆盖和有限测度截断证明；\(n\) 维平移、伸缩及与 Jordan 体积的一致性不得反向预用变量代换公式。
- 第57章 Vitali 不可测集的构造调用选择原则；“零测”“无内点”“第一纲”“基数较小”是不同概念，不得互相替代。
- 第58章简单函数逼近只使用可测性和扩充实值次序，不预用积分。Lusin 定理当前只对有限测度的 Lebesgue 可测集和几乎处处有限函数使用。
- 第59章先由简单函数定义非负积分，再证明单调收敛；不得用控制收敛或 Fatou 引理证明其自身。非负积分允许取 \(+\infty\)。
- 第60章 Fatou 引理由第59章单调收敛推出，控制收敛再由 Fatou 引理推出；正文中的证明顺序不得循环。带符号积分只有在正、负部不同时为 \(+\infty\) 时定义，\(L^1\) 函数则两部都有限。
- 第61章 Lebesgue 的 Riemann 可积性判别以“有界函数的不连续点集为零测集”为充要条件；不得省略有界闭区间和 Lebesgue 可测性的语境。零测修改保持 Lebesgue 积分，却一般不保持 Riemann 可积性。
- 第62章乘积测度和 Fubini 唯一性采用 \(\sigma\)-有限测度。Tonelli 先处理非负可测函数；带符号函数交换积分次序必须先验证绝对可积。
- 第63章参数积分的连续性和求导分别使用控制收敛；控制函数必须在共同参数邻域内有效。Leibniz 公式还需单独处理移动端点，不能只对固定区间套用求导定理。
- 第64章有限测度用于几乎处处收敛推出依测度收敛、一般连续复合、乘法以及 (L^q) 收敛推出 (L^p) 收敛；后一个蕴含的正文证明不得前向调用第67章 Hölder 不等式。全局依测度收敛在无限测度空间上比局部依测度收敛强。
- 第65章依测度收敛抽取几乎处处收敛子列不需要 \(\mu(X)<\infty\)；Egorov 定理和“每个子列都有几乎处处收敛再子列”的反向刻画按正文版本需要有限测度。
- 第66章一致可积性只排除高函数值上的质量集中；在无限测度空间上还须以质量紧性控制积分质量逃逸。有限测度 Vitali 定理直接使用依测度收敛和一致可积性；\(\sigma\)-有限版本使用局部依测度收敛、一致可积性与质量紧性，并通过对角子列和 Fatou 引理控制极限的空间尾部。
- 第67章 \(L^p\) 的元素是几乎处处等价类。Minkowski 和 Banach 空间结论要求 \(p\ge1\)；\(0<p<1\) 时只有拟范数型距离，不能调用凸三角不等式。
- 第68章 \(L^q\subseteq L^p\) 的一般包含只在有限测度空间中成立；无限测度空间和计数测度上的方向必须分别检验。\(L^\infty\) 使用本质上确界，不是逐点上确界。极限 \(p\to\infty\) 在一般测度空间上要求先有某个有限指数 \(p_0\) 的可积性；有限测度只是保证 \(L^\infty\subset L^{p_0}\) 的充分条件。
- 第69章有限测度支撑简单函数在任意测度空间的 \(L^p\) 中稠密，不需要预设 \(\sigma\)-有限性；关键是 \(f\in L^p\) 使正超水平集具有有限测度。\(C_c(\mathbb R^n)\) 的稠密性和磨光逼近依赖 Lebesgue 测度的正则性、平移连续性与 Tonelli 定理；对 \(0<p<1\) 的论证须使用 \(p\) 次拟范数估计，不得直接套用 Minkowski。
