## 判定标准

一个独立章原则上至少满足下列三项中的两项：

1. 有独立的核心概念或核心问题；
2. 有由若干主要定义、定理、证明、反例和应用组成的内部逻辑链；
3. 删除后会在前后理论之间留下明显的结构断点。

分类含义如下：

- **应独立**：章级闭环成立，可保留为独立章；在3.0版中仍可能因顺序或命名调整而改号。
- **建议合并**：内容必要，但更适合作为相邻理论章的一组节，不单独占章。
- **明显过载需要拆分**：当前章包含两个以上可独立发展的理论闭环，或引入了多个数学分支的基础语言。

分类不是篇幅判断。建议合并的材料可以写得很长；明显过载的章节也不表示现有内容多余。

## 汇总结论

- “建议合并”主要集中在同一理论的定义、刻画、证明工具和应用被拆成连续多章之处。
- “明显过载需要拆分”集中在旧第33、48、104、135、173、203章；这些章分别混合了多个可独立理论链。
- 3.0版不以减少内容为目标，而以统一章级闭环为目标。旧章的节、证明、反例和习题均应在后续迁移中按本表进入新章，不因合并而删减。
- 一般拓扑的必要部分前移到度量空间之后，先建立乘积紧致性，再进入 Banach–Alaoglu；一般拓扑不再晚于首次实质调用。
