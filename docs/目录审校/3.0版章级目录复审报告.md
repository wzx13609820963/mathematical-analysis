## 一、当前状态

3.0版采用七卷、二十九编、第0—148章，共149章。章号连续，无缺号和重复。本版处于“章级候选定稿”阶段：普通内容任务按本目录执行，但宏观设计任务仍可处理过载、遗漏、重复和依赖问题；完成最终宏观审校并创建 Git 标签后才正式冻结。

- 应独立：92章；
- 建议合并：113章；

三类合计211章。分类针对理论闭环，不按页数判断；逐章依据见 `2.0版第0至210章粒度审计.md`。

## 二、章级调整

旧目录把同一理论的定义、判据和证明阶段分成相邻小章。3.0版将数列极限、函数极限、Riemann积分、一致收敛、Fréchet微分、非负积分、Banach空间三大原理、Picard迭代等重新组织为章级闭环。

旧第33、48、104、135、173、203章包含多条理论链，已按审计结果拆分。宏观复审又处理了若干原先误判为“应合并”的高级主题：

- \(L^1\) Fourier 变换与 \(L^2\) Plancherel 理论分章；
- Riemann 映射定理与调和函数分章；
- 条件期望与鞅分章；
- Littlewood--Paley 理论与小波分章；
- 变分法直接方法与 Euler--Lagrange 方程分章；
- PDE 基本问题与一阶方程分章。

这些调整使少数高级章不再同时承担两个完整证明体系。导函数、\(L^p\) 包含关系和 Peano 存在定理等边界偏薄但核心问题明确的章暂予保留，正文形成后再依据实际理论闭环复核。

## 三、依赖关系

一般拓扑安排在 Banach--Alaoglu 之前，完整 Tychonoff 工具不再被泛函分析章节提前调用。第二卷卷首同时给出跳读与回读路线，使逻辑顺序不强迫初读者立即完成全部一般拓扑。

欧氏空间中的微分形式只证明参数化子流形上的 Stokes 公式和星形域 Poincaré 引理；抽象流形上的积分、边界定向和一般 Stokes 定理后置。奇异链、上链和奇异上同调已在 de Rham 定理之前单列，消除了“完整证明定理但未建立比较对象”的前置缺口。

第72章只建立 Lebesgue 微分定理所需的一维覆盖和极大估计；第121章建立 \(\mathbb R^n\) 中系统的极大算子理论。两处为明确的分层深化。正规族位于 Riemann 映射定理之前；单位分解位于流形积分之前；两种 Vitali 收敛定理在术语表中分名登记。

## 四、目录语言与粒度

复审前，149个章名中有121个含“与/及/、”，100章恰有6节，全部章都落在5—8节。复审后：

- 含上述并列连词的章名降为19个；
- “接口、预告、初步、机制、统一、重新解释”等作为元话语的目录项清零；
- 节数分布扩展为3—12节：3节1章，4节34章，5节73章，6节9章，7节14章，8节10章，9节7章，12节1章。

节数变化来自理论内容的合并或展开，不是随机制造差异。单一问题章压缩为四五节；实数构造、Riemann积分、多重积分、测度、Fourier变换、Banach空间、上同调与一阶PDE等枢纽章展开为八至十节。目录只写数学对象和结论；跨章用途、阅读提示和进一步联系移入卷首或正文。

## 五、范围与工程迁移

七卷共同构成综合分析教材。第一至第三卷建立经典分析、度量空间和Lebesgue理论；第四卷发展泛函分析、Fourier分析和弱解方法；第五至第七卷进入复分析与微分几何、概率与调和分析、算子理论与PDE。
